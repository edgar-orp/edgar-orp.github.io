# edgar-orp.github.io

Personal portfolio of Edgar Omar Reyes Páiz — Software Developer · Software Engineer · C# / Unity Specialist.

Live: https://edgar-orp.github.io

Static site built with HTML5, CSS3 and vanilla JavaScript. No build step, backend or external runtime dependencies. Typography uses local system fallbacks.

## Structure

- `index.html` — single-page portfolio
- `css/styles.css` — cyberpunk/hacker visual theme and responsive layout
- `js/main.js` — navigation, scroll spy, reveal effects, terminal effect and CV availability
- `js/i18n.js` — translation scaffold (English default)
- `assets/favicon.svg` — site favicon
- `images/projects/` — project screenshots (to be added)

## Deploy

GitHub → Settings → Pages → Deploy from a branch → `main` / `(root)`.
