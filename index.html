01 // about

Professional profile

I design, develop, test and deploy software for desktop systems, mobile devices, kiosks, touchscreens, events and dedicated hardware, including offline-first deployments. My primary language is C#, and Unity is my main area of specialization.

My work spans the full cycle: requirements analysis, architecture, implementation, debugging, testing, integration, deployment and production troubleshooting. I favor modular architectures built on SOLID principles and separation of concerns.

Through xrlab.dev I build custom software solutions and interactive systems, and I am expanding into broader software engineering, systems, automation and technology roles.

  • architecture

    Software architecture, OOP, SOLID and clean code; modular, reusable and event-driven systems.

  • interactive apps

    Real-time and interactive applications for desktop, mobile, kiosks, events and XR.

  • hardware integration

    Cameras, peripherals, Arduino, QR workflows and hardware/software interfaces, validated through testing.

  • linux & cross-platform

    Linux environments (Arch, Fedora, Debian), terminal workflows, Windows, Android, iOS and Nintendo platforms.

  • ai-assisted dev

    AI-powered workflows with OpenAI and local image-generation tools such as ComfyUI, Qwen and FLUX.
